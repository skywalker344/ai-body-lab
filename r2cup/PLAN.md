# R2カップ プロジェクト

## コンセプト
コーヒーカップ型のケースからR2-D2のドームが顔を出す、デスク置きの会話ロボット。
X-wingのソケットに収まっているイメージ。話しかけるとClaudeが答え、ドームが首を振る。

## 構成
- 頭脳：Mac（USB-C接続）
  - 音声認識 → Claude API → 音声合成／ビープ音再生
  - マイク・スピーカーはひとまずMac内蔵を使う
- 体：マイコン（ESP32-S3 推奨。USBシリアル直結、将来Wi-Fi化・I2Sスピーカー追加も可）
  - Macからシリアル通信で命令を受信（1行1命令のテキスト。例：`HEAD 30` / `LED BLINK 3`）
  - 首振りサーボ1個＋ロジックライト用LEDを制御
- 外装：3Dプリント
  - ドーム：MakerWorldのR2-D2モデル（The Elemental Brick）を流用、直径8〜9cmに縮小
  - カップ：オリジナル設計。中にマイコン・サーボ・（必要なら）スピーカーを収納
  - ケーブルはカップ底か取っ手から出す

## Mac側ソフト構成案（Python）
- 音声認識：mlx-whisper / whisper.cpp（ローカル・無料）
- 返答：Claude API。返答テキストと一緒に首振り・LED・感情を構造化して返させる
- 音声：ビープ音は `mac/r2voice.py` で自作合成。翻訳音声はまず `say -v Kyoko`

## 部品の手配状況
- [x] マイコン：ELEGOO ESP32開発ボード（初代ESP32・USB-C・2枚）※S3ではないが用途には十分

- [ ] アンプ：MAX98357A I2Sアンプモジュール
- [ ] スピーカー：直径28〜40mm 4Ω 3W（カップ上部に上向き設置が第一候補）
- [ ] 電解コンデンサ 470〜1000µF 10V以上（サーボ起動時のリセット対策）
- [x] 配線（ジャンパーワイヤー等）
- [ ] はんだごて（LED・アンプのはんだ付けに必要。手持ち未確認）

## 音の出し方
- R2本体のスピーカーから鳴らす。MacがUSBシリアル経由で音声データをESP32へ送り、MAX98357A→スピーカーで再生
- ケーブル1本で命令と音を送るので、首振りと音のタイミングを合わせやすい

## 決定事項
- しゃべり方：日本語は一切話さない。字幕も出さない。会話の文脈を把握して、返答として合いそうなビープ音を鳴らす
- キャラクター：好奇心旺盛で少し生意気、でも持ち主に忠実な相棒

## Mac側の使い方
```
cd r2cup/mac
# macOS標準のPython 3.9では動かない（anthropic SDKは3.10以上）。uvで3.12を使う
curl -LsSf https://astral.sh/uv/install.sh | sh   # 初回のみ
uv venv --python 3.12 && source .venv/bin/activate
uv pip install -r requirements.txt
export ANTHROPIC_API_KEY=...
python r2cup.py --text --fake --debug   # まずAPIなし・キーボードで動作確認
python r2cup.py --text --debug          # Claudeとキーボードで会話
python r2cup.py --debug                 # マイクで会話（--ptt で Enter を押して話す）
```
- 返事用モデルは標準で Haiku 5.5（約2.5秒）。`--model opus` で文脈の読みが深い Opus 5.5（3〜5秒）
- 返事を待つ間は音を鳴らさず、LEDを点滅させて首を左右にきょろきょろ動かす
- Claude は返事として「心の声（音には出さない）・最初の鳴き声・おしゃべりの雰囲気と長さ・首の角度・LED」を返す
- マイコンへの命令（`--port` 指定時）：`HEAD <-90〜90>` / `LED CALM|BLINK|FAST|RED|RAINBOW|OFF`

## 注意点
- 映画のR2効果音は使わない（著作権の申し立て対策）。ビープ音は自作する
  - 特徴（口笛のような滑らかなピッチ変化、トリル、早口の電子音、感情の起伏）は真似るが、音そのものは合成で作る
- MakerWorldモデルのライセンスを確認する（改造データの公開・販売時）
- サーボが動き出す瞬間の電流でマイコンがリセットされたら、電源を分ける
- 首振りの範囲内なら配線をたるませて対応し、スリップリングは不要
