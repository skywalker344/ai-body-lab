# X2D プレート交換アーム — Blender シミュレーション

`x2d_swap_anim.py` は、X2D のプレート交換の流れを Blender のシーンとアニメーション（600 フレーム、24fps、約 25 秒）として生成するスクリプトです。

## 使い方（Mac / Windows の Blender 4.x / 5.x）
1. Blender を起動し、上部の **Scripting** タブを開く
2. テキストエディタの **Open** で `x2d_swap_anim.py` を開く
3. **Run Script**（▶）を押す（シーン内のオブジェクトは作り直されます）
4. 3D ビューにマウスを置いて **Space** で再生する。テンキー **0** でカメラ視点になる

ヘッドレスでレンダリングする場合:
```
blender -b -P x2d_swap_anim.py -- --render out_frames --step 2
```

## 動作の順番
| 番号 | フレーム | 内容 |
|---|---|---|
| ① | 0–24 | 印刷完了 → GO（人がカメラで確認） |
| ② | 24–64 | T字ピンを刺し、90° 回してロック |
| ③ | 64–88 | 手前を 35mm 持ち上げ、磁石から剥がす |
| ④ | 88–196 | 受け台まで引き出す |
| ⑤ | 196–280 | 受け台を 35° 傾け、使用済みプレートと部品を回収箱へ落とす |
| ⑥ | 280–356 | マガジンから新品を 1 枚下ろす |
| ⑦ | 356–448 | 斜め 12° のまま奥のピンまで押し込む |
| ⑧ | 448–520 | 奥のピンを支点に手前を下ろす → 磁石で吸着 |
| ⑨ | 520–600 | プレートの自動認識が OK なら次の印刷へ |

## 寸法
- Web で公開されている値: X2D の外形 392×406×478mm、プレート 257mm 角
- **仮の値（実測して書き換える）**: `ZB`（ドア下端＝ベッド面の高さ）、`TAB_X`（ツメの位置）、`PIN_X`（奥のピン）、`HOOK_Y`（クリップの位置）、`RISER`（台の高さ）
- アーム: 上腕 95mm、前腕 95mm、先端 40mm、T字ピン 25mm（`layout2.py` の計算結果）。根元はプリンタ前面から 110mm 手前、中心から右へ 190mm

スクリプト冒頭の `params` を書き換えて再実行すれば、シーンが作り直されます。
